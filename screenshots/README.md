# Raw game screenshots

Generated by the **Screenshot Games** workflow
(`.github/workflows/screenshot-games.yml`, `scripts/screenshot_games.py`).
Each `<id>.png` is a 1280×800 headless-Chromium capture of the catalog game
with that exact `id`, taken a few seconds after load with a generic
click / Enter / arrow-key nudge. `manifest.json` records the outcome per game
(`ok`, `error`, `remote`) and `PLATFORM_REVISION` the platform commit captured.

These are **not thumbnails** and are not published to the Pages site:

- They are unreviewed frames for humans deciding how to illustrate a game.
  Many show title screens, black canvases, or games that need a real GPU.
- A capture here says nothing about display rights. Follow `AGENTS.md` and
  record provenance in `ARTWORK.md` before promoting anything to `thumbnails/`.
- Run the workflow manually (Actions → Screenshot Games) and use `only` /
  `limit` to restrict it; a full catalog pass takes a long time.
